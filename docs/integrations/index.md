# 통합

Home Assistant Core가 외부 시스템·디바이스·API와 연결되는 100+ 개의 통합 목록입니다. HACS 기반 [커스텀 컴포넌트](./custom-components.md)와 [ESPHome](./esphome.md) 디바이스는 별도 페이지에서 다룹니다.

## 카테고리 요약

| 카테고리              | 대표 통합                                                                                             |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| 코어 / 시스템         | Home Assistant, Supervisor, Recorder, History, Logger, HTTP, Frontend, Lovelace, MQTT, Matter, Thread |
| 모바일 / 알림         | Mobile App, Notify, Discord, SMTP, IMAP                                                               |
| 위치 / 존재           | iCloud, Private BLE Device, Proximity, Mobile App                                                     |
| 미디어                | Apple TV, Jellyfin, Plex, Music Assistant, Spotify, YouTube, Last.fm                                  |
| 음성 / AI             | Anthropic, OpenAI, Google Generative AI, Open Router, MCP, MCP Server                                 |
| 가전 / 디바이스       | LG ThinQ, Samsung SmartThings, Awair, Oral-B, Withings, Steam, Netatmo                                |
| 메트릭 / 옵저버빌리티 | Prometheus, Uptime, System Monitor, Cert Expiry, Version, RPi Power                                   |
| 외부 데이터           | Bitcoin, Alpha Vantage, GitHub, GDACS, WAQI, 17TRACK                                                  |
| 캘린더 / 일정         | Calendar, CalDAV, Local Calendar, Remote Calendar, Local To Do                                        |
| 자동화 보조           | Automation, Script, Scene, Template, Times of the Day, Workday, Holiday, Season                       |
| 백업 / 동기화         | Backup, Home Assistant Cloud (Nabu Casa)                                                              |

전체 표는 아래에 자동 생성된 형식으로 유지하며, 새 통합을 추가할 때 수동으로 갱신합니다.
