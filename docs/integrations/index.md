# 통합

Home Assistant Core가 외부 시스템·디바이스·API와 연결되는 100+ 개의 통합 목록입니다. Marketplace로 설치한 [커스텀 컴포넌트](./custom-components.md)와 [ESPHome](./esphome.md) 디바이스는 별도 페이지에서 다룹니다.

## 카테고리 요약

| 카테고리          | 대표 통합                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------- |
| 코어 / 시스템     | Home Assistant, Supervisor, Recorder, History, Logger, HTTP, Frontend, Lovelace, Marketplace, Raspberry Pi    |
| 프로토콜          | MQTT, Matter, Thread, OpenThread Border Router, Bluetooth, ESPHome, Shelly, Wyoming                           |
| 모바일 / 알림     | Mobile App, Home Assistant iOS, Discord, SMTP, IMAP                                                           |
| 위치 / 존재       | iCloud, Private BLE Device, Proximity, Traccar Server                                                         |
| 미디어            | Apple TV, Jellyfin, Plex, Music Assistant, Spotify, Last.fm, Radio Browser, Immich                            |
| 음성 / AI         | Anthropic, OpenAI, Google Gemini, OpenRouter, llama.cpp, ElevenLabs, MCP Client, MCP Server                   |
| 가전 / 디바이스   | LG ThinQ, Awair, Oral-B, Withings, OpenDisplay, Nintendo Switch parental controls                             |
| 네트워크 / 서비스 | UniFi Network, AdGuard Home, Cloudflare, Paperless-ngx, Mealie, Transmission                                  |
| 메트릭 / 모니터링 | SQL, Derivative, Uptime, System Monitor, Certificate Expiry, Version, Raspberry Pi Power Supply Checker, Ping |
| 외부 데이터       | Bitcoin, GitHub, GDACS, OpenUV, Electricity Maps, 17TRACK, Feedreader, Scrape, Speedtest.net                  |
| 캘린더 / 일정     | Local Calendar, Remote Calendar, Local To-do, Shopping list, Holiday, Workday                                 |
| 자동화 보조       | Automation, Script, Scene, Template, Group, Utility Meter, Times of the Day, Schedule, Flux                   |
| 백업 / 동기화     | Backup, Home Assistant Cloud (Nabu Casa)                                                                      |
